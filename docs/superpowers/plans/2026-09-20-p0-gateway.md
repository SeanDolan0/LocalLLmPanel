# P0 Gateway Completeness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the unified gateway to proxy chat + completions + embeddings with CORS and hint-list 404s, plus one-click Continue/Cursor configs.

**Architecture:** Keep hand-rolled `TcpListener` HTTP in `gateway.rs`; generalize `proxy_chat` into `proxy_post`; add embed routing mirror; add CORS headers centrally. Frontend only extends the existing Settings gateway card.

**Tech Stack:** Rust (tokio, reqwest, serde_json), React/TS Settings card, `cargo test`.

**Spec:** `docs/superpowers/specs/2026-09-20-p0-gateway-design.md`

## Global Constraints

- No new backend dependencies (keep minimal-deps ethos).
- Gateway binds `127.0.0.1` only; forward-only auth via existing `apply_vllm_auth`.
- Unknown model → 404 JSON with `running` hint list; no auto-start.
- FIM/completions body passed through verbatim; embeddings non-streaming.
- CORS `Access-Control-Allow-Origin: *` on all gateway responses.

## Review Focus

- `POST /v1/embeddings` with embed-only model routed to embed server, not instruct — expect 200-path proxy, not 404.
- `POST /v1/completions` with FIM `suffix` field preserved verbatim upstream — expect suffix intact.
- Browser `OPTIONS` preflight from Continue web UI — expect 204 + CORS headers.
- `GET /health` from a polling client — expect `{"status":"ok"}` with no model field required.
- Unknown model on any POST route — expect 404 JSON listing running models, not plain-text `not found`.

```rust
/// Route a requested embedding model name to the port of the running
/// server that serves it. Mirrors find_server_port_for_model but for
/// task == "embed".
pub fn find_server_port_for_embed(
    servers: &BTreeMap<String, crate::state::LiveServer>,
    model: &str,
) -> Option<u16> {
    let m = model.trim();
    if m.is_empty() {
        return None;
    }
    let running: Vec<&crate::state::LiveServer> = servers
        .values()
        .filter(|ls| ls.status == crate::state::ServerStatus::Running && ls.def.task == "embed")
        .collect();
    for ls in &running {
        if ls.def.effective_model_name().eq_ignore_ascii_case(m)
            || ls.def.model_id.eq_ignore_ascii_case(m)
        {
            return Some(ls.def.port);
        }
    }
    let lower = m.to_lowercase();
    for ls in &running {
        let hf = ls.def.model_id.to_lowercase();
        let name = ls.def.effective_model_name().to_lowercase();
        if hf.ends_with(&lower) || name.ends_with(&lower) || lower.ends_with(&hf) {
            return Some(ls.def.port);
        }
    }
    None
}
```

Place directly after `find_server_port_for_model` (after line 74).

```rust
fn running_model_names(
    servers: &BTreeMap<String, crate::state::LiveServer>,
    task: &str,
) -> Vec<String> {
    servers
        .values()
        .filter(|ls| {
            ls.status == crate::state::ServerStatus::Running && ls.def.task == task
        })
        .map(|ls| ls.def.effective_model_name())
        .collect()
}

fn not_found_payload_with_hint(model: &str, kind: &str, running: &[String]) -> String {
    serde_json::json!({
        "error": {
            "message": format!(
                "no running {kind} server for model '{model}'. Running: [{}]",
                running.join(", ")
            ),
            "type": "invalid_request_error",
        },
        "running": running,
    })
    .to_string()
}
```
